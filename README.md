# Student Performance Analysis Using Python

## Project Overview
This project focuses on analysing student academic performance using Python. It explores student data, identifies patterns, performs statistical analysis, and presents insights through data visualisation and an interactive dashboard.

The project was completed as part of the **YuvaIntern Data Analysis Internship**.

## Objectives
- Collect and understand student academic data.
- Clean and preprocess the dataset.
- Perform Exploratory Data Analysis (EDA).
- Apply statistical analysis and modelling.
- Create an interactive dashboard.
- Generate meaningful insights about student performance.

## Tools and Technologies
- **Python** – Programming language
- **Pandas** – Data manipulation and cleaning
- **NumPy** – Numerical operations
- **Matplotlib & Seaborn** – Data visualisation
- **Streamlit** – Interactive dashboard
- **Jupyter Notebook** – Data analysis and experimentation

## Dataset
The project uses the Student Performance dataset (`student-mat.csv`).

The cleaned dataset is also included as `cleaned_student_data.csv`.
